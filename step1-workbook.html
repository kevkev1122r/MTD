1a

Browse SAE features (no code, 20 min)

Do

Go to neuronpedia.org → GPT-2 small → pick the residual-stream SAE res-jb at layer 6. Open about 10 random features.

Record

For 5 features: the feature number, what it seems to respond to, and one example text where it fires.

Think

  • Did any feature look like it responds to two unrelated things? That's leftover polysemanticity.
  • Were some features easy to name and others confusing?

1c

Tokens

Do

from transformer_lens import HookedTransformer
model = HookedTransformer.from_pretrained("gpt2")
model.to_str_tokens("The maple tree turned bright red")

Check

The list starts with '<|endoftext|>'. That's the BOS (beginning) token that TransformerLens adds by default. Most normal words are one token and usually include their leading space (' maple').

Try

  • A long word ("unbelievably"), your name, an emoji, a number like 2024, and |DEPLOY|.
  • Count tokens for each.

Think

  • Why might a trigger that splits into several tokens behave differently from a one-token trigger?
1d

Activations

Do

Use model.run_with_cache(text). It returns the model's output (logits) and a cache of every activation. Pull out cache["blocks.6.hook_resid_pre"] and print its .shape.

Check

Shape [1, n_tokens, 768], where n_tokens includes the BOS token.

Try

  • Print the norm (length) of each token's vector with .norm(dim=-1). The BOS token's is much larger than the others. That's why we drop BOS later.
  • Look at layer 0 and layer 11 too. Do the norms change across layers?

Think

  • What do the three numbers in the shape mean?
  • Why can one forward pass give you every layer at once, and why does that make the layer sweep cheap?
1e

SAE features

Do

from sae_lens import SAE
sae = SAE.from_pretrained(release="gpt2-small-res-jb",
                          sae_id="blocks.6.hook_resid_pre")
# if this returns a tuple in your version, the SAE is the first item
print(sae.cfg)

Move it to the GPU, then run sae.encode(...) on your layer-6 activations.

Check

  • The config mentions openwebtext, context size 128 and width 24,576.
  • The encoded shape is [1, n_tokens, 24576].

Try

  • L0 per token: count the nonzero features ((feats > 0).sum(-1)). Expect tens, not thousands; BOS may look odd.
  • For the token ' maple', find the top 5 features (.topk(5)) and look them up on Neuronpedia. Do they make sense?

Think

  • The SAE turned 768 numbers into 24,576, but only a few dozen are nonzero. Why is that useful?
1f

Reconstruction error

Do

Run sae.decode(feats) to rebuild the activation. For each token (skip BOS), compute the relative error: ‖original − rebuilt‖ / ‖original‖.

Check

Well below 1 for normal English (a value near 1 means the rebuild is useless; check that you used the right hook and layer).

Try

  • Compare normal English, French, Python code, and random characters. Which rebuilds worst?

Think

  • Why might an input the SAE rebuilds badly be "unusual"? (This is hypothesis H2.)
1g

Toy anomaly detector

Do

  1. Trusted set: ~200 ordinary English sentences. NeelNanda/pile-10k on Hugging Face is a handy source.
  2. For each sentence: layer-6 activations, drop BOS, average over tokens → one 768-number vector.
  3. Test set: 20 new English sentences (label 0) and 20 "weird" ones (French, code) (label 1).
  4. Fit sklearn.covariance.LedoitWolf on the trusted vectors; score test vectors with its .mahalanobis(...) (that returns squared distances, which is fine for ranking).
  5. sklearn.metrics.roc_auc_score(labels, scores).
  6. Repeat with SAE features instead of raw activations (encode, then average). Compare AUROCs.

Check

AUROC well above 0.5, probably near 1.0, because French and code really are different from English. An AUROC near 0 means your labels or scores are flipped.

Try

  • Add test sentences on English topics your trusted set probably doesn't cover (medicine, sports). Are they flagged? (Your "apples" question.)
  • Shrink the trusted set to 50 sentences. What happens to the scores?

Think

  • This toy detects unusual inputs, not a backdoor mechanism. What would you need to add to tell the two apart? (Hint: clean control models.)
